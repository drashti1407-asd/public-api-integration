# Product Explorer

## About
Product Explorer is a React.js web application that fetches and displays product information from the DummyJSON public API.

Users can search for products and filter them by category.

## Features

- Fetch products from a public API.
- Display product images and details.
- Search products by name.
- Filter products by category.
- Search and filter products together.
- Display loading messages while fetching data.
- Display error messages if API requests fail.
- Display a message when no products are found.
- Responsive design for desktop, tablet and mobile devices.

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite
- DummyJSON API

## API Used

Products API:

https://dummyjson.com/products?limit=0

API Documentation:

https://dummyjson.com/docs/products

## Installation and Setup

1. Clone the repository:

   `git clone https://github.com/drashti1407-asd/public-api-integration.git`

2. Open the project folder:

   `cd public-api-integration`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL displayed in the terminal.
